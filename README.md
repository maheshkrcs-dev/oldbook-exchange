# 📚 OldBook Exchange

A full-stack web application to **buy and sell old books easily**.

---

## 🚀 Features

- 🔐 User Authentication (Login/Register)
- 📚 Sell old books with image upload
- 🔍 Search books
- 🛒 Cart system
- ❤️ Wishlist
- 💬 Chat system (basic)
- 👤 User profile with image upload
- 📦 Order management
- 🛠 Admin dashboard

---

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, Bootstrap
- **Backend:** PHP (MySQLi)
- **Database:** MySQL
- **Server:** Apache (LAMP / Docker)
